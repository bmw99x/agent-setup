# Journal template

For the human, not the next agent. Use tables and bullets, no prose paragraphs. This is the place for detail.

```markdown
# Journal: <topic>
> <YYYY-MM-DD> · brief: ./brief.md

## Domain context
- <problem, users, data, why it matters>

## Assumptions: then → now
| Started believing | Now believe | What changed it | Evidence |
|---|---|---|---|

## Inflection points
1. **<moment>**: <before> → <after>. Trigger: <result or user quote>.

## Paths explored
### <path name> · <measured | user-decided | claimed | parked>
- **What:** <one line>
- **For:** <bullets>
- **Against:** <bullets>
- **Settled by:** evidence / constraint / preference / time. <number or quote>
- **Reopen if:** <condition>

## User decisions
| Decision | Yes/No | User's words |
|---|---|---|

## Narrative
- <≤10 bullets: how the understanding developed>
```
