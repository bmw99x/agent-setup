# Brief template

Fill every section. Write "none" when a section is empty and keep the heading. Every cell states a fact and its source.

```markdown
# Brief: <topic>
> <YYYY-MM-DD> · supersedes: <previous brief path | none> · journal: ./journal.md

## Goal
> <user's own words, quoted>

## Domain
- <who uses it, data sizes, rates, invariants: one fact per bullet>

## Constraints
| Constraint | Source | Reopen if |
|---|---|---|
| <rule> | user / contract / system | <condition that would lift it> |

## Measured
| Finding | Number | Scope (dataset, env) |
|---|---|---|

## Closed and parked paths
| Path | Settled by | Reason / evidence | Reopen if |
|---|---|---|---|
| <option> | evidence / constraint / preference / time (= parked) | <number or quote> | <threshold or event a reader could check> |

## Untested claims
| Claim | Made by | What would test it |
|---|---|---|

## Open questions
- <question with no implied answer>

## Never explored
- <adjacent option nobody tried>
```
