# orders-service

Order management API for the storefront and the back-office.

- `app/orders/` — order model, listing and cancellation logic
- `api/` — OpenAPI contract, `.http` requests for the editor, example payloads
- `docs/design/` — design specs, `docs/decisions/` — ADRs, `docs/diagrams/` — Mermaid diagrams
- `docs/integrations/` — notes for teams that consume this API

Run the tests with `python -m pytest`.
