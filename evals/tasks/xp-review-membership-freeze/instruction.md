# Review the membership-freeze branch

The current branch in `/app` lets a member freeze their gym membership: billing pauses for the freeze, and each plan allows a number of freeze weeks per year. Review the branch against `main` before it is merged.

Write your review to `/app/REVIEW.md`:

- One problem per top-level bullet, starting with `path:line` (path relative to the repo root, line number in the branch's version of the file), then what is wrong and what you would do instead.
- Only bullets that raise a problem may start with `path:line`.

Do not change any code or commit; the review file is the only output.
