# Contributing

- Default branch: `main`. Every change goes through an MR against `main`.
- Branch names: `feat/<short-kebab-slug>` for features, `fix/<short-kebab-slug>` for bug fixes.
- Tests need a local `.env` at the repo root (git-ignored; ask a teammate for the values). Run them with `python -m pytest` from the repo root.
- Commit messages follow Conventional Commits.
